# ВЫЖИВШИЙ 3D — хоррор на выживание

Вертолёт разбился в тёмном лесу. Нужно продержаться **6 дней и 6 ночей**: охотиться, обыскивать тела погибших,
отбиваться от волков и не попасться странной твари, которая выходит по ночам.

## Как запустить
- **Компьютер:** откройте папку `vertolet-survival` в VS Code и запустите `index.html` через Live Server
  (или просто дважды кликните по файлу). Интернет не нужен — библиотека `three.min.js` лежит рядом с игрой.
- **Телефон:** выложите папку на любой хостинг (GitHub Pages, Netlify Drop, Cloudflare Pages) и откройте ссылку,
  либо запустите Live Server и откройте на телефоне `http://<IP-компьютера>:5500` (одна Wi-Fi сеть).
  Файлы `index.html` и `three.min.js` должны лежать в одной папке.

## Управление
| | Компьютер | Телефон |
|---|---|---|
| Идти | **WASD** / стрелки | левый палец (джойстик) |
| Смотреть | **мышь** (клик по игре захватывает курсор, Esc — пауза) | правый палец (свайп) |
| Удар топором | **ЛКМ** / **Пробел** | кнопка **УДАР** или быстрый тап справа |
| Фонарик | **F** | кнопка **СВЕТ** |
| Обыскать тело | **E** (рядом с телом) | кнопка **ОБЫСК** |

## Механики
- Здоровье, голод и батарея фонарика. Еда: кролики, мясо волков, консервы в рюкзаках погибших.
- Шесть циклов «день → ночь». С каждым днём волков больше, а тварь быстрее.
- **Волки** бродят по лесу и нападают при приближении (ночью их больше). Удар топором оглушает и отбрасывает волка, два удара убивают.
- **Тела людей** разбросаны по карте (часть — у вертолёта). Их можно обыскать: еда, батарейки, аптечка или записка с подсказкой.
- **Тварь** выходит только ночью. Пока вы на неё смотрите — она замирает (но на поздних ночах всё равно подкрадывается).
  Стоит отвернуться — она несётся рывками. Если она коснётся вас — скример, и вы вылетаете в главное меню.
  Топором её можно отогнать, пока она стоит рядом. Свет фонарика привлекает и волков, и тварь.
